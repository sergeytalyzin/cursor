   ```typescript
   // Было:

   // Станет:

     queryKey: ['sales'],
     queryFn: () => fetchSalesData()
   });
   ```

3. **Настройте axios** (`/src/shared/config/axios.ts`):
   - Добавьте API ключи
   - Настройте headers
   - Добавьте обработку ошибок
