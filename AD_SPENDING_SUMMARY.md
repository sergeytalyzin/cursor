## 🔧 API endpoints (из документации)

### 1. Получение токена
```
POST /api/client/token
Host: https://api-performance.ozon.ru
```

### 2. Список кампаний
```
GET /api/client/campaign
Authorization: Bearer {token}
```

### 3. Статистика по кампаниям
```
POST /api/client/statistics
Authorization: Bearer {token}
Body: { campaigns, dateFrom, dateTo, groupBy }
```

### 4. Статистика по товарам
```
GET /api/client/statistics/campaign/product
Authorization: Bearer {token}
Params: dateFrom, dateTo
```

## 🔑 Как настроить

### Шаг 1: Получите credentials

1. Личный кабинет Ozon → **Настройки → API-ключи**
2. Создайте сервисный аккаунт (или используйте существующий)
3. Добавьте новый ключ
4. Скопируйте `client_id` и `client_secret`

### Шаг 2: Обновите код

В файле `/src/pages/AdSpending/AdSpending.tsx` (строки 27-29):

```typescript

const PERFORMANCE_CLIENT_ID = 'XYZ@advertising.performance.ozon.ru';
const PERFORMANCE_CLIENT_SECRET = 'your_client_secret_here';

// На ваши реальные:
const PERFORMANCE_CLIENT_ID = '90423286@advertising.performance.ozon.ru';
const PERFORMANCE_CLIENT_SECRET = 'ВАШ_CLIENT_SECRET';
```

**Формат client_id:**
```
{номер_сервисного_аккаунта}@advertising.performance.ozon.ru
```

## 💡 Как работает

### 1. Получение токена
```typescript
POST /api/client/token
{ client_id, client_secret, grant_type: "client_credentials" }

↓

{ access_token: "eyJh...", expires_in: 1800 }
```

### 2. Запрос данных с токеном
```typescript
GET /api/client/campaign
Authorization: Bearer eyJh...

↓

{ list: [ {id, title, state, ...}, ... ] }
```

### 3. Агрегация и расчёт
```typescript
// ROI
adROI = ((revenue - adSpent) / adSpent) * 100

// Доля рекламы
adShare = (adSpent / revenue) * 100

// CTR
ctr = (clicks / views) * 100

// Конверсия
conversion = (orders / clicks) * 100
```
