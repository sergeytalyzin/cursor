## 🎨 Анимации и эффекты

### Hover эффект на карточках:
```
Обычное состояние:
┌─────────────┐
│   Card      │  transform: translateY(0)
│   Content   │  box-shadow: 0 2px 8px
└─────────────┘

При наведении:
  ┌─────────────┐
  │   Card      │  transform: translateY(-4px)
  │   Content   │  box-shadow: 0 12px 32px
  └─────────────┘
     ↑ поднятие
```

### Loading state:
```
⬤ ⬤ ⬤  →  ⚪ ⬤ ⬤  →  ⬤ ⚪ ⬤  →  ⬤ ⬤ ⚪
         пульсация спиннера
```

### Fade-in анимация:
```
Появление элемента:
0%:   opacity: 0, translateY(+10px)
100%: opacity: 1, translateY(0)
Длительность: 0.4s
```

## 📊 Типографика

### Размеры шрифтов:

```
H1: 32px  - Заголовки страниц (не используется)
H2: 28px  - Не используется  
H3: 24px  - Не используется
H4: 20px  - Заголовки карточек
H5: 16px  - Подзаголовки

Body: 14px  - Основной текст
Small: 12px - Вторичный текст
Large: 16px - Крупный текст

Числа в KPI: 32-48px (жирный)
```

### Веса шрифтов:

```
400 - Regular (основной текст)
500 - Medium (кнопки, подзаголовки)
600 - Semibold (заголовки карточек)
700 - Bold (большие числа)
```
