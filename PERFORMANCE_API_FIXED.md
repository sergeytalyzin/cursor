## 🐛 Возможные проблемы

### 1. CORS ошибка
**Симптом:** В консоли ошибка "blocked by CORS policy"

**Решение:** 
- Performance API может блокировать запросы из браузера
- Нужно настроить прокси в Vite или использовать серверную часть

### 2. Неверные credentials
**Симптом:** Ошибка 401 Unauthorized

**Решение:**
- Проверьте client_id и client_secret в личном кабинете
- Убедитесь что аккаунт активен

### 3. Нет кампаний
**Симптом:** Пустой список кампаний

**Решение:**
- Создайте рекламные кампании в кабинете Ozon
- Проверьте что кампании активны

### 4. Токен истёк
**Симптом:** Ошибка "token expired"

**Решение:**
- Токен обновляется автоматически
- Перезагрузите страницу
